AI Bookmark Organizer

This plugin uses AI to organize your Firefox bookmarks. The bookmarks are automatically assigned to clusters based on their content.
  • You need an OpenAI API key to run the plugin.
  • Only the bookmarks from the Other bookmarks folder in the Bookmarks menu are organized.
  • Cluster folders are created inside the Organized Bookmarks folder.
  • Unreachable pages can be found under Organized Bookmarks/Unreachable.
  • A bookmark may be renamed if its current name doesn't reflect the content (see GPT Prompt below).
